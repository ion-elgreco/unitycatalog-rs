unitycatalog-rs¶

A Rust reimplementation of Unity Catalog OSS, the open catalog for data and AI. It has upstream's REST APIs (Unity Catalog, Delta and Iceberg REST), a web UI, the uc CLI and a Python client. It keeps the catalog in an embedded database (Turso) or in PostgreSQL.

pip install 'unitycatalog-rs[all]'
uc dev

Quickstart Install

  • Server

    Run uc-server on your machine, in Docker or on Kubernetes. Keep the catalog in PostgreSQL, sign users in, and give clients credentials for S3, ADLS and GCS.

    Run the server

  • Clients

    The uc CLI and its terminal UI, the Python client, the web UI, and the REST APIs for engines such as Polars, deltalake and PyIceberg.
