CLI commands¶

Each command of uc is uc <entity> <operation> [flags]. uc <entity> <operation> --help shows the same flags as this page. The flags in bold are required.

Every command also takes the global options:

Option Description
--server <url> The server. Default: UC_CLI_SERVER, else cli.server, else http://localhost:8080.
--auth_token <token> The token of the requests. Default: UC_CLI_TOKEN, else cli.token, else the sign-in of uc auth login to the server.
--output <format> table (the default), json or jsonPretty.
--config <file> The settings file, instead of UC_CONFIG or uc.toml.

The list commands take --max_results (default 100) and --page_token. After a full page, uc prints the option for the next page to standard error, such as Next page: --page_token sales. The lists of users and groups page with --start_index: the server gives at most 1000 of them in one page, and uc prints the option for the next page while there are more.

catalog¶

Operation Flags
create --name, --comment, --properties, --storage_root
list --max_results, --page_token
get --name
update --name, and one or more of --new_name, --comment, --properties
delete --name, --force (also delete its schemas and what they hold)

--properties is a JSON object: '{"team": "sales"}'.

Operation Flags
create --catalog, --name, --comment, --properties, --storage_root
list --catalog, --max_results, --page_token
get --full_name (catalog.schema)
update --full_name, and one or more of --new_name, --comment, --properties
delete --full_name, --force (also delete what it holds)

table¶

Operation Flags
create --full_name (catalog.schema.table), --columns, --format, --table_type, --storage_location, --properties
list --catalog, --schema, --max_results, --page_token
get --full_name
delete --full_name
read --full_name, --max_results (rows; default 100)
write --full_name: writes 15 random rows
  • --columns: "id INT, price DECIMAL(10,2)". The types are BOOLEAN, BYTE, SHORT, INT, LONG, FLOAT, DOUBLE, DATE, TIMESTAMP, TIMESTAMP_NTZ, STRING, BINARY and DECIMAL(p,s). A DECIMAL needs both a precision p from 1 to 38 and a scale s from 0 to p.
  • --format: DELTA (the default), ICEBERG, CSV, JSON, AVRO, PARQUET, ORC, TEXT or LANCE. Only DELTA gets a Delta table at the location; read and write work with Delta tables.
  • --table_type: EXTERNAL (the default), which needs --storage_location, or MANAGED.
  • When a Delta table is already at the location of an EXTERNAL table, create keeps it. --columns must then have its columns, with the same names and types, in the same order.

permission¶

Operation Flags
get --securable_type, --name, --principal

user¶

Operation Flags
create --name, --email, --external_id
list --filter (SCIM, such as 'userName eq "alice@example.com"'), --start_index (from 1), --count (default 100)
get --id
update --id, --name, --external_id, --email
delete --id: deletes the user with its grants, tokens and group memberships; its objects have no owner then

A user's email is its name in grants and owners. update --email replaces the user's primary email and keeps its other emails. It moves the user's grants, owned objects and tokens to the new email. A userName that was the old email changes with it, so the old email is free for another user. A userName from an identity provider stays.

Operation Flags

auth¶

Operation Flags
login --identity_token: exchanges it for a token of the server; without it, signs in in the browser. Keeps the token as the sign-in to the server, for the next commands.
logout Removes the sign-in to the server.
