class unitycatalog.tables.ColumnInfo(name: str,type_json: str,*,type_text: str | None = None,type_name: ColumnTypeName | str | None = None,type_precision: SupportsIndex | None = None,type_scale: SupportsIndex | None = None,type_interval_type: str | None = None,position: SupportsIndex | None = None,comment: str | None = None,nullable: bool | None = None,partition_index: SupportsIndex | None = None,)¶

A column of a table.

Attributes

  • comment (str | None) – User-provided free-form text description.
  • name (str) – Name of the column.
  • nullable (bool | None) – Whether the column can hold null values. The server sets false when it is absent.
  • partition_index (int | None) – Position of the column in the partition key of the table.
  • position (int | None) – Position of the column, starting at 0.
  • type_interval_type (str | None) – Format of an interval type.
  • type_json (str) – Full data type of the column as a JSON Spark StructField.
  • type_name (ColumnTypeName | None) – Name of the data type of the column.
  • type_precision (int | None) – Digits of precision. Required for decimal types.
  • type_scale (int | None) – Digits to the right of the decimal point. Required for decimal types.
  • type_text (str | None) – Full data type of the column as SQL text, such as decimal(10,2).

class unitycatalog.tables.StagingTableInfo¶

A staging table: a table id and managed storage location reserved for a MANAGED table that a client is about to create.

Attributes

  • catalog_name (str) – Name of the parent catalog.
  • id (str) – Unique identifier of the staging table. The table gets it when it is created.
  • name (str) – Name of the table, relative to the parent schema.
  • schema_name (str) – Name of the parent schema.
  • staging_location (str) – Storage location URL reserved for the table. Create the table with it as its storage_location.

Get a table.

Parameters

  • read_streaming_table_as_managed (bool | None, optional) – Show a streaming table as a MANAGED table, as upstream's server can. This server does not read it.
  • read_materialized_view_as_managed (bool | None, optional) – Show a materialized view as a MANAGED table, as upstream's server can. This server does not read it.
  • include_browse (bool | None, optional) – Also answer a caller who sees the table through the BROWSE privilege only, with its discovery fields and browse_only set.

Returns

  • TableInfo – A table: data in the third layer of the three-level namespace, below a schema.

Async: get_async(…) → Future[TableInfo]

class unitycatalog.tables.TableInfo¶

A table: data in the third layer of the three-level namespace, below a schema.

Attributes

  • browse_only (bool | None) – True when the table has only the discovery fields that the BROWSE privilege allows.
  • catalog_name (str) – Name of the parent catalog.
  • columns (list[ColumnInfo]) – The columns of the table.
  • comment (str | None) – User-provided free-form text description.
  • created_at (int) – Time at which the table was created, in epoch milliseconds.
  • created_by (str | None) – Username of the creator of the table.
  • data_source_format (DataSourceFormat | None) – File format of the data of the table.
  • name (str) – Name of the table, relative to the parent schema.
  • owner (str | None) – Username of the owner of the table.
  • properties (dict[str, str]) – Key-value properties of the table.
  • schema_name (str) – Name of the parent schema.
  • storage_location (str | None) – Storage location URL of the table. Absent for views.
  • table_id (str) – Unique identifier of the table.
  • table_type (TableType | None) – Type of the table.
  • updated_at (int) – Time at which the table was last changed, in epoch milliseconds.
  • updated_by (str | None) – Username of the user who last changed the table.
  • view_definition (str | None) – Definition of a view-like table: SQL for views, YAML for metric views.
  • view_dependencies (DependencyList | None) – The tables and functions that a view-like table reads.

class unitycatalog.tables.TableType¶

The type of a table.

Members

  • MANAGED – A table whose data Unity Catalog manages, below the managed storage of its schema or catalog.
  • EXTERNAL – A table whose data is at a storage location that the user gives.
  • STREAMING_TABLE – A streaming table.
  • MATERIALIZED_VIEW – A materialized view.
  • METRIC_VIEW – A metric view: its definition is YAML.
  • VIEW – A view: its definition is SQL.
