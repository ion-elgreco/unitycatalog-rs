Attributes

  • file_modification_timestamp (int) – Time at which the commit file was last changed, in epoch milliseconds.
  • file_name (str) – Name of the staged commit file under _delta_log/_staged_commits, without a path.

  • timestamp (int) – The in-commit timestamp, in epoch milliseconds.
  • version (int) – Version of the commit.

class unitycatalog.delta.DeltaClusteringDomainMetadata(*, clustering_columns: Any | None = None)¶

The domain metadata of a clustered table.

Attributes

  • clustering_columns (list[list[Any]]) – The clustering columns. Each one is a list of strings: the path from the root of the schema to the column, with physical names when column mapping is on. An empty list is sent too: the table is clustered by no columns.

class unitycatalog.delta.DeltaStagingTableResponse¶

A staging table: the table id and storage location that the server reserves for a new MANAGED table, and what the first commit must contain.

Attributes

  • location (str) – The storage location of the table.
  • required_properties (dict[str, Any]) – Table properties that the table must have. Each value is a string, or null when any valid value is allowed.
  • required_protocol (DeltaProtocol | None) – The protocol that the first commit must have at least.
  • storage_credentials (list[DeltaStorageCredential]) – Temporary credentials to write the first commit.
  • suggested_properties (dict[str, Any]) – Table properties that the table should have. Each value is a string, or null when the client makes the value.
  • suggested_protocol (DeltaSuggestedProtocol | None) – Features that the client should enable when it can.
  • table_id (str) – Unique identifier of the table.
  • table_type (DeltaTableType | None) – Type of the table. Always MANAGED.

class unitycatalog.delta.DeltaStructField(name: str,data_type: Any,nullable: bool,metadata: Any,)¶

A field of a Delta struct type, as in the Delta protocol schema format.

Attributes

  • data_type (Any) – Data type of the field: a string for a primitive type (long, decimal(10,2)), or an object with a type of array (element-type, contains-null), map (key-type, value-type, value-contains-null), struct (fields) or decimal (precision, scale).

  • nullable (bool) – Whether the field can hold null values.

class unitycatalog.delta.DeltaTableUpdate(action: str,*,updates: Any | None = None,removals: SupportsGetItem[int, str] | None = None,columns: DeltaStructType | None = None,comment: str | None = None,commit: DeltaApiCommit | None = None,uniform: DeltaUniformMetadata | None = None,latest_published_version: SupportsIndex | None = None,protocol: DeltaProtocol | None = None,domains: SupportsGetItem[int, str] | None = None,partition_columns: SupportsGetItem[int, str] | None = None,last_commit_version: SupportsIndex | None = None,last_commit_timestamp_ms: SupportsIndex | None = None,)¶

One update action. The action says which fields are set: - set-properties: updates, property names to string values. - remove-properties: removals. - set-columns: columns. - set-table-comment: comment. - add-commit: commit and uniform. - set-latest-backfilled-version: latest_published_version. - set-protocol: protocol. - set-domain-metadata: updates, domain names to their metadata: delta.clustering to {"clusteringColumns": [["a"], ["b", "c"]]}, delta.rowTracking to {"rowIdHighWaterMark": 9}. - remove-domain-metadata: domains. - set-partition-columns: partition_columns. - update-metadata-snapshot-version: last_commit_version and last_commit_timestamp_ms.

Attributes

  • action (str) – Kind of the update: one of the actions above.
  • columns (DeltaStructType | None) – For set-columns: the new columns of the table.
  • comment (str | None) – For set-table-comment: the new comment of the table.
  • commit (DeltaApiCommit | None) – For add-commit: the commit to add.
  • domains (list[str]) – For remove-domain-metadata: the domain names to remove.
  • last_commit_timestamp_ms (int | None) – For update-metadata-snapshot-version: timestamp of the last commit, in epoch milliseconds (delta.lastCommitTimestamp).
  • last_commit_version (int | None) – For update-metadata-snapshot-version: version of the last commit (delta.lastUpdateVersion).
  • latest_published_version (int | None) – For set-latest-backfilled-version: the commits up to this version are backfilled.
  • partition_columns (list[str]) – For set-partition-columns: names of the partition columns. An empty list is sent too: it removes the partitioning.
  • protocol (DeltaProtocol | None) – For set-protocol: the new protocol. It replaces the protocol of the table.
  • removals (list[str]) – For remove-properties: the property keys to remove.
  • uniform (DeltaUniformMetadata | None) – For add-commit: UniForm metadata to commit with the commit.
  • updates (dict[str, Any]) – For set-properties: property names to string values. For set-domain-metadata: domain names to their metadata objects.

class unitycatalog.delta.DeltaCredentialOperation¶

The access level of a storage credential.

Members

  • READ – Read the data.
  • READ_WRITE – Read and write the data.

class unitycatalog.delta.DeltaMaintenanceOperation¶

A maintenance operation that the catalog allows on a table, in addition to the operations that the Delta protocol allows.

Members

  • DATA_REORGANIZATION – Rewrite the data files of the latest version to group, cluster or lay out the data, without a change to the data.
  • DATA_CLEANUP – Delete old data files, without a change to the data of the latest version.
  • METADATA_CLEANUP – Delete old metadata files, without a change to the data of the latest version.

class unitycatalog.delta.DeltaTableType¶

The type of a Delta table.

Members

  • MANAGED – A table whose data Unity Catalog manages.
  • EXTERNAL – A table whose data is at a storage location that the user gives.
