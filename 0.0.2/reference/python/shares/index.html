class unitycatalog.shares.DataObject(name: str,data_object_type: DataObjectType | str,*,added_at: SupportsIndex | None = None,added_by: str | None = None,comment: str | None = None,shared_as: str | None = None,partitions: SupportsGetItem[int, Partition] | None = None,cdf_enabled: bool | None = None,history_data_sharing_status: HistoryStatus | str | None = None,start_version: SupportsIndex | None = None,string_shared_as: str | None = None,status: DataObjectStatus | str | None = None,)¶

Attributes

  • added_at (int | None) – The time when this data object is added to the share, in epoch milliseconds.
  • added_by (str | None) – Username of the sharer.
  • cdf_enabled (bool | None) – Whether to enable cdf or indicate if cdf is enabled on the shared object.
  • comment (str | None) – A user-provided comment when adding the data object to the share.
  • data_object_type (DataObjectType | None) – Type of the data object.
  • history_data_sharing_status (HistoryStatus | None) – Whether to enable or disable sharing of data history. If not specified, the default is DISABLED.
  • name (str) – A fully qualified name that uniquely identifies a data object.
  • partitions (list[Partition]) – Array of partitions for the shared data.
  • shared_as (str | None) – A user-provided new name for the data object within the share.
  • start_version (int | None) – The start version associated with the object.
  • status (DataObjectStatus | None) – Whether the data object is still accessible to the share.
  • string_shared_as (str | None) – A user-provided alias for a non-table data object (e.g. a volume) within the share.

Whether a shared data object is still accessible to the share.

Members

  • ACTIVE – The data object is accessible.
  • PERMISSION_DENIED – The share owner lost access to the data object.

class unitycatalog.shares.DataObjectType¶

The server shares TABLE, VOLUME and AGENT_SKILL objects, and refuses the other types.

Members

  • TABLE
  • SCHEMA
  • VIEW
  • MATERIALIZED_VIEW
  • STREAMING_TABLE
  • MODEL
  • FUNCTION
  • VOLUME – A Unity Catalog volume shared as a storage-backed asset (OpenSharing).
  • AGENT_SKILL – An agent skill (a directory of SKILL.md + scripts/assets) shared as a storage-backed asset on top of a volume (OpenSharing).

class unitycatalog.shares.HistoryStatus¶

Members

  • DISABLED – Data history sharing is disabled.
  • ENABLED – Data history sharing is enabled.

class unitycatalog.shares.PartitionValueOp¶

The operator a partition value is matched with.

Members

  • EQUAL – The partition column equals the value.
  • LIKE – The partition column matches the value as a SQL LIKE pattern.
