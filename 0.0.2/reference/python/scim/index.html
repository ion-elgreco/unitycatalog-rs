class unitycatalog.scim.ListScimGroupsResponse¶

A page of SCIM groups.

Attributes

  • items_per_page (int) – Number of groups in the page.
  • resources (list[ScimGroup]) – The groups.
  • schemas (list[str]) – SCIM schema URIs of the response: urn:ietf:params:scim:api:messages:2.0:ListResponse.
  • start_index (int) – Index of the first group of the page, from 1.
  • total_results (int) – Number of groups that match.

class unitycatalog.scim.ScimAuthenticationScheme¶

A way to authenticate to the SCIM endpoints.

Attributes

  • description (str) – Description of the scheme.
  • name (str) – Name of the scheme.
  • primary (bool) – Whether this is the preferred scheme.
  • spec_uri (str | None) – URL of the specification of the scheme.

class unitycatalog.scim.ScimBulkConfig¶

How the server supports SCIM bulk requests.

Attributes

  • max_operations (int) – The maximum number of operations in a bulk request.
  • max_payload_size (int) – The maximum size of a bulk request, in bytes.
  • supported (bool) – Whether bulk requests are supported.

class unitycatalog.scim.ScimBulkOp(method: str,path: str,*,bulk_id: str | None = None,data: Any | None = None,)¶

One operation of a SCIM bulk request (RFC 7644, section 3.7).

Attributes

  • bulk_id (str | None) – Identifier of the operation, which the result repeats.
  • data (dict[str, Any] | None) – The body of the operation: a ScimUser or ScimGroup for POST and PUT, a ScimPatchOp (without id) for PATCH.
  • method (str) – The HTTP method of the operation: POST, PUT, PATCH or DELETE.
  • path (str) – The resource of the operation: /Users or /Groups for POST, /Users/<id> or /Groups/<id> for the others.

class unitycatalog.scim.ScimBulkOpResult¶

The result of one operation of a SCIM bulk request.

Attributes

  • bulk_id (str | None) – The bulk_id of the operation.
  • location (str | None) – Path of the resource that the operation created or changed, such as /scim2/Users/<id>.
  • method (str) – The HTTP method of the operation.
  • response (dict[str, Any] | None) – The SCIM error of a failed operation.
  • status (str) – The HTTP status of the operation, such as 201.

class unitycatalog.scim.ScimBulkResponse¶

The answer to a SCIM bulk request: one result per operation that ran, in order.

Attributes

  • operations (list[ScimBulkOpResult]) – The results of the operations.
  • schemas (list[str]) – SCIM schema URIs of the response: urn:ietf:params:scim:api:messages:2.0:BulkResponse.

class unitycatalog.scim.ScimGroup¶

A SCIM 2.0 group of users.

Attributes

  • display_name (str) – Name of the group, its name in grants.
  • external_id (str | None) – The identity the group has at an identity provider.
  • id (str) – Unique identifier of the group. The server assigns it.
  • members (list[ScimGroupMember]) – Members of the group: users.
  • meta (ScimMeta | None) – When the group was created and last changed.
  • schemas (list[str]) – SCIM schema URIs of the resource: urn:ietf:params:scim:schemas:core:2.0:Group. Requests send the key even when empty; the server fills it in.

class unitycatalog.scim.ScimGroupMember(value: str,*,display: str | None = None,member_type: str | None = None,ref: str | None = None,)¶

A member of a SCIM group.

Attributes

  • display (str | None) – A display string, which clients set to the name of the user.
  • member_type (str | None) – The SCIM resource type of the member: User.
  • ref (str | None) – URL of the user. The server sets it and ignores it in requests.
  • value (str) – The id of the user.

class unitycatalog.scim.ScimPatchOperation(op: str,*,path: str | None = None,value: Any | None = None,)¶

One operation of a SCIM PATCH request (RFC 7644, section 3.5.2).

Attributes

  • op (str) – The operation: add, remove or replace, in any case.
  • path (str | None) – SCIM attribute path: attr, attr.sub, attr[filter] or attr[filter].sub, such as name.familyName, members[value eq "<id>"] or emails[type eq "work"].value. Absent for an add or replace whose value holds the attributes.
  • value (Any) – The value. Any JSON: a string for displayName, an array of members for members, an object of attributes without path. A remove of a list with a value removes those values.

class unitycatalog.scim.ScimSchemaAttribute¶

An attribute of a SCIM schema (RFC 7643, section 7).

Attributes

  • canonical_values (list[str]) – The values that the attribute usually has, such as work and home.
  • case_exact (bool | None) – Whether text values compare with their case: never.
  • description (str | None) – Description of the attribute.
  • multi_valued (bool | None) – Whether the attribute holds a list of values.
  • mutability (str | None) – Whether a client may change the attribute: readOnly, readWrite or immutable.
  • name (str) – Name of the attribute, such as userName.
  • reference_types (list[str]) – What a reference attribute refers to, such as external.
  • required (bool) – Whether a resource must have the attribute.
  • returned (str | None) – When the server returns the attribute: default.
  • sub_attributes (list[ScimSchemaAttribute]) – The attributes of a complex attribute.
  • type (str) – Data type of the attribute: string, boolean, reference or complex.
  • uniqueness (str | None) – How the server keeps values unique: none or server.

class unitycatalog.scim.ScimUser¶

A SCIM 2.0 user. Its principal, its name in grants and owners, is its primary email, else its first email, else its user name.

Attributes

  • active (bool | None) – Whether the user can sign in. Absent: enabled; a new user without it gets true.
  • display_name (str | None) – Name of the user, for display.
  • emails (list[ScimEmail]) – Email addresses of the user. When the principal changes, the grants, owned objects and tokens of the user move to the new one.
  • external_id (str | None) – The identity the user has at an identity provider. An application's own token names the user whose external id is the name of the issuer block and the client id, such as entra:<client id>.
  • id (str) – Unique identifier of the user.
  • meta (ScimMeta | None) – When the user was created and last changed.
  • name (ScimName | None) – The parts of the name of the user.
  • photos (list[ScimPhoto]) – Pictures of the user.
  • roles (list[ScimRole]) – Roles of the user. Only /scim2/Me sends them: the role admin for a caller that can do what the metastore admin does. The server ignores roles in requests.
  • schemas (list[str]) – SCIM schema URIs of the resource: urn:ietf:params:scim:schemas:core:2.0:User.
  • user_name (str) – The unique name of the user, such as a user principal name, in any case. Absent in a create request: the principal.
