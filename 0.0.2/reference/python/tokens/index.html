The classes of the tokens API.

class unitycatalog.tokens.ListPatsResponse¶

Attributes

  • next_page_token (str | None) – Opaque token of the next page. Absent on the last page.
  • tokens (list[PatInfo]) – The tokens.

class unitycatalog.tokens.PatInfo¶

A personal access token of a user. The server keeps a hash of the token only: the token itself is in the response of CreateToken and nowhere else.

Attributes

  • created_at (int) – Time at which the token was created, in epoch milliseconds.
  • expires_at (int | None) – Time at which the token expires, in epoch milliseconds. Absent or 0: the token does not expire.
  • id (str) – Unique identifier of the token.
  • name (str) – Name of the token.
  • owner (str) – Username of the owner of the token.
  • token_prefix (str) – The first 8 characters of the token, for display only.
  • token_value (str | None) – The token. Set only in the response of CreateToken.
