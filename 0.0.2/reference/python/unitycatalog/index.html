unitycatalog¶

Python client for unitycatalog-rs, the Rust reimplementation of Unity Catalog OSS.

Client wraps the Rust uc-client. It takes the root URL of the server. Each method comes twice: name waits for the response, and name_async returns an awaitable. The requests on one catalog, schema, table and so on are on its handle, such as client.catalog("main"):

import asyncio
from unitycatalog import Client

client = Client("http://localhost:8080/")
client.create_catalog("main", comment="primary")
print([c.name for c in client.list_catalogs()])

async def main():
    catalog = await client.catalog("main").get_async()
    print(catalog.id)

asyncio.run(main())

The classes of the requests and responses are in a module per API package, such as unitycatalog.tables, with the enums of that package. Enums are enum.StrEnum classes; a parameter takes a member or its name. An error answer raises UnityCatalogError, or the subclass of its HTTP status, such as NotFoundError.

With sign-in, Client(url, token=...) sends a fixed token, and Client(url) signs in with the identity of the environment: an Azure or Google identity, an OAuth client, or a token in UC_TOKEN. Client(url, token_provider=...) names the token source: one of unitycatalog.identity, or a callable that returns the token.
