# HTTP API

The operations of the server's HTTP APIs, with their parameters, request bodies and responses:
the Unity Catalog REST API, the Delta REST API, the Iceberg REST catalog, Delta Sharing and the
control plane. Scalar shows them from the [OpenAPI document](openapi.json), which comes from the
protos in `proto/` that the server's routes and the clients follow.
